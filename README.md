# Diversidade — Diferentes, mas iguais nos direitos

Website de sensibilização sobre **diversidade, inclusão e igualdade de direitos**.

**Projeto escolar** — Módulo 03 · Criação de Páginas Web  
Curso Técnico de Gestão de Equipamentos Informáticos · 2026/2027  
Escola Europeia de Ensino Profissional

## Tema
**Diversidade: diferentes, mas iguais nos direitos**

Enquadra-se no Plano de Turma («Conhecer os nossos direitos, fazer escolhas conscientes e respeitar a diversidade») e nas competências de TIC e Cidadania.

## Estrutura das páginas
1. **Início** — mensagem de sensibilização e navegação
2. **Sobre o Tema** — contextualização, conceitos (tabela), dados
3. **Problema / Desafio** — causas, consequências, população afetada
4. **Saber Mais** — dimensões da diversidade, vídeo (placeholder), ligações
5. **O que podemos fazer?** — comportamentos, boas práticas, proposta de intervenção
6. **Recursos** — instituições, documentos, materiais
7. **Questionário** — formulário interativo (demo sem servidor)
8. **Contactos / Fontes** — autores, referências, créditos

## Funcionalidades
- Design moderno e responsivo (Tailwind CSS)
- Alternância de idioma **PT / EN**
- Menu sticky + menu móvel
- Princípios básicos de acessibilidade (contraste, foco, skip link, alt/aria)
- Tabela de conceitos, formulário, hiperligações internas e externas
- Pronto para adicionar vídeo, áudio e imagens reais

## Como visualizar
Abrir `index.html` no browser (ou servir a pasta com um servidor local simples).

```bash
# Exemplo com Python
python -m http.server 8080
```
